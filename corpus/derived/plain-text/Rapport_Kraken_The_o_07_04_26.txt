⚔ DÉTAIL DES ÉCHANGES
► Pierre — N8N vs Claude Code pour l’intégration produit
Contexte : Pierre utilise déjà un workflow N8N fonctionnel pour l’intégration produit de A à Z. La question était
de savoir s’il y avait un intérêt à migrer vers Claude Code.
Verdict du coach : vu que le workflow N8N de Pierre fonctionne sans erreur, il n’y a pas d’intérêt majeur à tout
refaire dans Claude Code. En revanche, Claude Code est pertinent pour les modifications ponctuelles
(corrections en masse, changement d’appellation sur 200 produits, etc.) là où N8N nécessiterait un nouveau
workflow.
Approche recommandée : utiliser N8N pour la création en série (80 % des cas stables) et Claude Code pour
les modifications ad hoc. Tester en parallèle le même produit via N8N et via Claude Code pour comparer la
qualité du résultat.

► Emeric — Structure de projet Claude Code
Découverte clé : Emeric a présenté une architecture de projet Claude Code en trois fichiers fondateurs :
claude.md (contexte projet, lu automatiquement à chaque session), agent.md (instructions détaillées, accès,
sous-agents) et queue.md (todo list de tâches à accomplir).
Principe : à chaque lancement de Claude Code, le fichier claude.md est lu en premier. Il oriente ensuite Claude
vers les bons fichiers (agent, skills, memory) selon la demande. Emeric a montré qu’à partir de ces 3 fichiers,
Claude Code a créé automatiquement toute une arborescence de skills, de prompts et de templates.

► Emeric — Nanocorp : agents autonomes
Nanocorp est une plateforme (beta) qui crée un business de manière autonome : landing page, Stripe,
emailing, prospection automatique. Modèle économique : 20 % de commission sur les revenus générés.
Financé par Y Combinator, projet français basé aux USA.
Retour d’Emeric : testé en une soirée. L’outil a créé automatiquement une landing page, un lien Stripe, un
scoring d’audit Google Business et des templates d’email. Résultat intéressant pour tester une idée, mais pas
encore prêt pour un vrai business. Crédits gratuits limités, certaines fonctions manquantes (Google Ads pas
encore dispo).
Inspiration : Emeric a reproduit le principe dans Claude Code en créant manuellement les fichiers claude.md /
agent.md / queue.md, puis en laissant Claude générer le reste. Le résultat était comparable en qualité et plus
contrôlable.

► Mika — Template de documentation de projets
Mika a partagé un document de référence pour structurer la documentation de projets Claude Code. Ce
template crée automatiquement une architecture complète (configuration, développement, déploiement, guides)
avec un fichier start.md qui oriente Claude vers la bonne catégorie selon le besoin.
Intérêt : chaque process est répertorié, ce qui évite que Claude touche au hasard à des éléments sensibles.
Particulièrement utile pour les projets complexes (applications, SaaS) et pour retrouver l’information plusieurs
mois après.
► Singrid — Automatiser la recherche de prix AliExpress
Problème : Singrid doit remplir un tableau de marges ROAS/ROSBE pour toute sa boutique (+150 produits).
Elle effectue manuellement la recherche de prix d’achat via recherche par image sur AliExpress, ce qui prend
plusieurs jours.
Solution proposée par le coach : utiliser RapidAPI AliExpress (8 €/mois, 300 requêtes/jour) connectée à
Claude Code. Process : exporter le CSV Shopify → Claude récupère l’image du produit → recherche par image
via RapidAPI → analyse des 3-5 premiers résultats (prix, note, disponibilité) → ajout du prix + lien AliExpress
dans le CSV.
Important : tester produit par produit avant de lancer en boucle. Toujours vérifier manuellement les résultats.
« À partir du moment où c’est répétitif et c’est quasiment la même chose, ça peut s’automatiser. Et il
y a vraiment pas de valeur ajoutée que tu le fasses à la main. »
— Coach Kraken
► Aude — Premiers pas avec Claude
Aude débute dans la formation et n’a pas encore utilisé Claude. Le coach recommande de commencer par la
version gratuite, de créer un projet dédié dans Claude et d’y expliquer son activité (e-commerce,
dropshipping, niche choisie). Ainsi, chaque future conversation bénéficiera du contexte.
L’outil Beautica (pour faire porter des vêtements à des mannequins virtuels) a été mentionné, recommandé par
une autre élève. Mika propose également un outil similaire avec quelques crédits gratuits pour tester.
« Utilise Claude et crée un projet. Le premier truc, c’est lui expliquer ce que tu fais. Même en audio,
tu en as pour 2 minutes. Comme ça, tout ce qui va suivre, il comprendra. »
— Coach Kraken

► Le piège de la dispersion avec l’IA
Discussion collective sur un problème partagé par tous : l’IA permet de faire tellement de choses qu’elle pousse
à tester au lieu de produire. Le coach insiste : le mot clé est FOCUS. Si le site n’est pas lancé ou ne tourne
pas bien, toute l’énergie doit aller sur le site. Les tests, aussi séduisants soient-ils, ne remplacent pas
l’exécution.
« Focus. C’est vraiment le mot. Il y a plein de trucs qui sortent, il y a plein de trucs à tester, mais
faites déjà votre site, développez-le. »
— Coach Kraken
